# 근태 탭 — 사용자 요구사항

HR(hr.krs.co.kr) 근태 신청·신청 내역·취소. 출장의 여비·증빙은 [trip.md](trip.md). 동작 설명은 `README.md` 「근태 탭」.

## 신청 폼

- 2026-10-03 — 신청 내역을 기간을 정해 조회하는 동안에는 폼이 접힌다(목록을 보려는 것이라서). 기본 기간으로 돌아오면 접기 전 모양으로.
- 2026-10-06 — 출장의 날짜·시각은 두 줄(출발일+출발 시각, 도착일+도착 시각), 그 아래 며칠간 한 줄.
- 2026-10-08 — "연차는 시작일과 종료일이 같은 줄에 있고 아래에 1,2,3,4,5d 버튼을 주고 오른쪽에 오전,오후" → 휴가 폼은 시작일·종료일 한 줄 + `1D`~`5D` + 오전·오후.
- 2026-10-08 — "1d 면 전일" → 전일 칩은 따로 두지 않는다. `1D` 에 오전·오후를 고르지 않은 것이 전일.
- 2026-10-08 — "9시 18시 이면 오전은 9시부터 12시, 오후는 13시 부터 18시 … 8시 부터면 12시 까지, 7시 부터면 11시 까지" → 반차 시간대는 그 날 출근시간 기준: 오전 = 출근~12시(네 시간 넘지 않게), 오후 = 13시~퇴근.
- 2026-10-08 — "오전/오후 반차는 사용할 수 없으니 알람을 줄 수 있도록" → 출근이 정시가 아닌 날(08:30·09:30)은 반차를 쓸 수 없다. 알람을 띄우고 결재요청·임시저장을 잠근다.
- 2026-10-09 — "연차사용의 경우 승인 전후 신청 내역에서 추가로 신청할 수 있도록" → 이미 올린 연차(결재요청·결재완료)에 기념일 지원을 신청 내역에서 붙인다. 연차를 다시 올리지는 않는다.
- 2026-11-03 — (구글 캘린더 화면 캡처 — `[출장-정인철] 선박용 CO2 포집 단위 모듈 시험(울산, KSC)` · `[휴가-백재해]` · `[오후반차-문창재]` 꼴의 일정) "근태 올릴때 구글 캘린더에 이런식으로 넣을 수 있게 옵션을 넣어줘. 사전정산, 차량조회 옆에 G캘린더... 이렇게" (물어서 고름: 일정 창을 채워 열기 — API 로 바로 넣기가 아니라) → 폼의 옵션 줄(사전정산·차량 조회 옆)에 `G캘린더` 체크. 켜고 결재요청하면 올라간 뒤 구글 캘린더 「일정 만들기」 창을 `[종류-내 이름] 목적(출장지, 장소)` 제목·날짜·시간으로 채워 새 탭에 연다 — 캘린더를 고르고 [저장]은 사람이 누른다. 임시저장에서는 열지 않는다. 유연근무에는 없다.

## 신청 내역

- 2026-10-04 — 기본 보기는 오늘부터 잡힌 것 전부 + 지난 것은 **여비 정산이 덜 끝난 출장만 다녀온 뒤 4주까지**(그 전에는 일주일 전부터 한 달 뒤까지). 사후정산을 완료했거나 증빙을 보낸 출장, 임시저장·반려·회수한 지난 출장, 지난 외근·휴가는 기본 보기에 없다. 홈 카드도 같은 규칙 → [trip.md](trip.md).
- 2026-10-04 — 지난 내역(히스토리) 버튼을 뺀다. 달력 버튼으로 시작일~종료일 조회 기간을 한 줄로 편다.
- 2026-10-04 — `4W`·`8W` 는 누르면 그 기간을 곧바로 조회한다(조회를 따로 누르지 않는다).
- 2026-10-04 — 출장 줄에는 정산 상태 딱지(정산전 · 사전정산 중 · 사전정산 완료 · 사후정산전 · 사후정산 중 · 정산완료)를 붙인다.
- 2026-10-04 — 줄 왼쪽 딱지는 근태의 결재 상태: 올려 둔 것은 `신청`, 결재완료는 `승인`, 임시저장·반려·회수는 HR 이름 그대로. 색으로 가린다.
- 2026-10-05 — "신청내역 조회 할때 그냥 4주전 8주전 이거 여기에 버튼 넣어주라 그냥 4W, 8W 라고 하면 될듯" → 4주·8주를 조회 기간 칸 안에서 제목 줄 오른쪽 버튼으로.
- 2026-10-05 — "사전 정산도 가서 볼 수 있게 사전 정산1도" → 사후정산 단계 줄에도 사전정산 아이콘 1 을 함께 세운다.
- 2026-10-05 — "여비계산서 기준으로 관리하도록 했는데... 여기에 계산서 새로고침이 없네" → 아이콘 맨 왼쪽에 여비계산서 다시 읽기(↻).
- 2026-10-07 — 취소신청서가 결재돼도 원 문서는 HR 목록에 결재완료로 남으므로, 패널이 올린 취소신청을 적어 두고 `취소 중`·`취소` 로 보인다.
- 2026-10-08 — (보고) 조회 기간이 출장기간을 다 덮지 않는다는 줄만 보였다 → 계산서 목록은 보이는 출장 줄의 출장기간을 다 덮게 읽는다.
- 2026-11-03 — (HR 공지 「기결재 근태 수정 프로세스 변경」 — 기존 취소신청 → 취소결재 완료 → 신규 근태 상신 → 신규 결재완료, 변경 수정신청 → 수정결재 완료. HR › 근태 › 근태신청 › 근태수정신청에서 행의 [수정] → 근태사항 수정 → [결재요청]) "근태 수정에서 이거 반영해줘" → 결재완료 건의 `근태 변경`은 취소신청을 올리지 않고 HR 근태수정신청으로 고쳐 올린다 — 누르면 같은 내용이 폼에 불러와지고, 고친 뒤 결재요청하면 원 문서의 수정결재요청이 된다(임시저장은 없다). 기존 근태는 수정결재가 승인될 때까지 그대로다. 승인 전 건(회수 후 수정)과 `취소신청` 버튼은 그대로.

## 유연근무 — 출퇴근 위반

- 2026-10-27 — "유연에 내 출근/퇴근 실제 시간이랑 기록되어 있는 시간이랑 비교해서 시간 위반한 내역을 볼 수 있도록" → 유연 종류를 고르면 HR 자율출퇴근 체크리스트의 날마다 출근·퇴근 기록을 그 날의 근무시간(계획)과 맞춰 위반한 날만 보인다(지각·조퇴·기록 없음). (기록 없음은 철회 2026-10-27)
- 2026-10-27 — "출퇴근 없음은 빼줘.. 왜냐면 2,3일 걸려 나올려면 그냥 그건 고려하지 않겠어. 출장,휴가 이런것도 대상이 아니겟지?" → 출근·퇴근 기록이 없는 것은 위반으로 보지 않는다(기록이 2~3일 늦게 올라온다). 있는 기록만 지각·조퇴로 본다. 하루 전체 출장·휴가는 대상이 아니고, 반차·외출처럼 몇 시간짜리 근태는 그 시간만 뺀다.
- 2026-10-27 — "이거 기간을 3개월 6개월 12개월 버튼 넣어줘" → 제목 줄의 `4W`·`8W` 오른쪽에 `3M`·`6M`·`12M` — 누르면 그 달 수만큼 전부터 오늘까지를 곧바로 읽는다. 4W·8W 는 그대로 둔다.
- 2026-10-27 — "이거 조퇴면.. 조퇴 표기를 해줘 시간을 알수 없네.." (물어서 고름: 위반한 시각을 표시) → 위반 줄의 시각 가운데 지각이면 출근 시각, 조퇴면 퇴근 시각을 붉게 표시한다.
- 2026-10-27 — "지각 3분이면 버튼에 출퇴근 시간 변경 으로 이동할 수 있게 아니고. 출퇴근 시간 변경 기능을 추가해줘." → 위반 줄에서 HR 「출/퇴근기록 변경신청」을 패널에서 바로 한다 — 변경 출근·퇴근 시각과 사유를 넣고 결재요청(HR 화면으로 보내는 링크가 아니다).
- 2026-10-27 — "출퇴근 위반이 발생하면 여기에 뜨고 수정할 수 있또록 해줘" (WORKSPACE 카드) · "워크스페이스는 1주일 이전까지만 보이게 해줘. 탭에는" (물어서 고름: 위반만 1주일) → WORKSPACE 카드에 지난 7일의 출퇴근 위반이 뜨고 거기서 바로 변경신청한다. 근태 탭(유연)에는 고른 기간의 위반이 전부 보인다. → [mine.md](mine.md)
