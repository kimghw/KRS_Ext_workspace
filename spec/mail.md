# 메일 탭 — 사용자 요구사항

보낸 메일의 회신 추적(`mailtrack/`). 동작 설명은 `mailtrack/README.md`.

- 2026-10-15 — "별도 폴더에 작성합니다 … 지금 프로젝트와 가능한 분리해서 작성해 주시기 바랍니다" → 메일 탭은 패널과 떨어진 폴더(`mailtrack/`)로, 패널이 import 하는 입구 하나만.
- 2026-10-15 — "메일 수신후 다운로드 받을 때 … 내용이나 첨부 파일 다운받을 수 있는 id도 같이 다운받게" → 내려받는 메일·첨부에 메일 ID·첨부 ID 를 함께.
- 2026-10-15 — "종료 기능이 없네" · "등록한 메일을 취소하는 기능이 안보임" (접힌 "추적 관리" 안에 있었음) → 추적 끝내기는 회신 현황 줄 오른쪽에, 등록 지우기는 ZIP 단추 밑에 바로 보이게. 접힌 관리 칸은 없앤다 → [panel-ui.md](panel-ui.md).
- 2026-10-16 — 상세의 차례: 보낸 메일 → 수신처별 회신 → 받은 회신(받은 아이콘).
- 2026-10-17 — 보낸 메일의 첨부는 회신 현황(진행률) 위, 같은 카드 안에(따로 있던 "보낸 메일 · 첨부" 카드는 없앤다). 보낸 메일 라벨에 보냄 아이콘.
