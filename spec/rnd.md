# R&D 탭 — 사용자 요구사항

R&D 과제의 예산·참여인력·연구개발 계획·진행 기록·변경이력. rERP 연동과 인건비는 [rerp.md](rerp.md). 동작 설명은 `README.md` 「R&D 탭」, YAML 뽑기·고치기는 `rndgen/README.md`.

## 과제와 차년도

- 2026-10-08 — R&D 탭 신설: 과제마다 올해(차년도)의 예산·참여연구자·연구개발 계획·진행 기록·변경이력을 적어 둔다.
- 2026-10-08 — 과제는 별칭으로 다룬다(칩·머리에 별칭, 과제명은 툴팁). 별칭은 필수, 겹치지 않게.
- 2026-10-08 — 연구개발계획서 YAML(RND 폴더의 `KR_<과제>.yaml` 스냅샷)을 끌어 놓기·붙여 넣기·고르기로 넣는다.
- 2026-10-08 — 차년도 YAML 을 뽑는 RND 프로젝트의 Claude Code 스킬 다섯 개를 복사해 두고 zip 으로 내려받게 한다. (철회 2026-10-16) "이 확장은 YAML 을 뽑지 않는다(스킬 zip 만)" — 아래 10-16 으로 뒤집힘.
- 2026-10-11 — 예산 정보가 없는 차년도 칩은 회색(점선). "비활성 차년도면 이전 차년도 기록 대신 R&D 설정을" → 넘어갈 수는 있지만 지난 차년도의 기록을 보이지 않는다.
- 2026-10-16 — "+ 누르면 Yaml 파일을 넣던지 아니면 사업계획서를 넣으면 과제의 YAML을 추출 … 그 스킬은 '차년도 YAML 뽑는 스킬' 거기 있지 … 변경사항의 내용을 임의 형식으로 제공 하면 yaml 로 수정해서 업데이트" → ＋ 카드에서 YAML 또는 사업계획서로 과제를 만들고, 변경사항 글로 YAML 을 고친다.
- 2026-10-16 — "여기서 모든 차년도, 추출기능 넣어줘" → 차년도 고르기에 모든 차년도(1차년도부터 차례로).
- 2026-10-16 — "과제 고치기에 있어야 하는게 아니라 job_id 찾기를 자동으로 하고 여기 페이지에서 맞는지 확인하면 버튼은 사라지고 Jobid 저장만" → Job Id 는 자동으로 찾아 카드에서 확인·저장. 폼 안의 찾기 버튼은 없다 → [panel-ui.md](panel-ui.md).
- 2026-10-16 — "이게 과제 고치기가 뭐냐? 아이콘으로 SSCB 글자 우측에 넣어주던지" → 과제 고치기는 별칭 옆 연필 아이콘.
- 2026-10-16 — "이거 어떤 과제인지 선택이 안되잖아" → 고치는 중인 과제의 칩은 켜진 채로.
- 2026-10-17 — "계정 코드(회계 I/O)는 과제 정보 아래 두고, 계정과목코드·계정명 테이블은 예산 안에 rERP 집행내역처럼 접어서 한 줄로" → 회계 I/O 는 과제 정보에, 계정과목별 예산 표는 예산 칸의 접힌 한 줄로.
- 2026-10-17 — "R&D 에서 과제 등록 할때 jobid 갖어 오는데 … 계정과목코드 계정과목명, 예산부서코드 또는 I/O 입력 예산금액도 같이 조회 … e-accounting.krs.co.kr 에 조회할 수 있도록" → 회계(e-accounting)에서 과제의 I/O 와 그 해 계정과목별 예산을 읽어 과제에 둔다. 구매요청서 예산 내역을 여기서 채운다 → [gongmun.md](gongmun.md).

## 예산

- 2026-10-11 — 예산 칸은 천원 단위(숫자만 적으면 천원, 단위를 붙이면 그 단위).
- 2026-10-11 — 집행률 막대는 몫마다 색이 다르다(미청구·사용계획 각기). 체크 상자 자체가 그 색이라 따로 범례 점은 두지 않는다.
- 2026-10-11 — "R&D 설정에서 어떤 항목을 볼지 고르게" → 예산 칸에 보일 비목 체크. 끈 비목은 예산 줄에서만 숨고 합계·복사·rERP 표에는 든다.
- 2026-10-11 — 집행에 더하기의 승인전 체크를 뺀다(rERP 집행비율에는 rerp 식대로 든다). 비목 더하기 단추도 뺀다("일단 필요 없을 것 같다" — 비목은 계획서의 여섯 비목, × 로만 뺀다).
- 2026-10-11 — R&D 설정은 탭 맨 아래, 공문 설정과 같은 카드 한 줄.

- 2026-10-16 — "참여연구자 및 행정 지원.. 으로 해서 행정지원 사람 넣을 수 있도록" → 참여연구자 표 아래에 과제마다 손으로 적는 행정지원 줄(이름·맡은 일·공문 참조). 공문 참조로 둔 사람은 그 과제의 모든 구매·교육·출장 공문의 참조자 → [gongmun.md](gongmun.md).
