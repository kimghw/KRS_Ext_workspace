# 회의실·차량 예약 탭 — 사용자 요구사항

동작 설명은 README 「사용」·「차량 이용」.

- 2026-10-28 — "회의실이 추가되었는데 이거 회의실 예약 리스트에 반영해줘"(부산 드롭다운에 1·2·3회의실(2층), 소·대회의실(7층·12층) 일곱 곳이 새로 생김) → 새 방을 격자에서 미팅룸 바로 아래에 1→3회의실, 7층 소→대, 12층 소→대 차례로 세운다. 접지 않는다.
- 2026-10-28 — "이거 위치 사용자가 정할 수 있게 해줘. 드래그 하면 되잖아" → 격자의 회의실 이름을 끌어 놓아 줄 차례를 바꾸고, 그 차례를 저장한다(창이 여러 개여도 같은 차례). 끌어서 정하기 전과 처음 보는 방은 위 규칙대로.
